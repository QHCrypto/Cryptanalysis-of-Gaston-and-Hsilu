## 真实置换采样

```bash
./build/gaston_dl verify \
  --candidates results/new_box/top.csv \
  --top-per-round 4 --rotations 0,1,7 \
  --samples 4194304 --seed 20261015 --threads 4 \
  --start-round last --constants reference \
  --output results/new_verification

python3 tools/report.py \
  --search results/new_box \
  --verification results/new_verification \
  --output results/new_box
```

`--samples` 是每个候选的样本对数，每对计算 F(X) 和 F(X⊕Δ)。`--top-per-round 4 --rotations 0,1,7` 对每轮前 4 个代表及其 3 个移位分别采样；各组使用派生的独立种子。基于计数索引的 SplitMix64 生成状态，同一配置改变线程数不会改变结果。它用于可复现的仿真实验，不提供信息论随机性证明。

默认 `--start-round last` 按参考实现选取末 R 轮，即零起始轮号 s=12−R。采样函数为：

1. 直接对均匀状态 X 应用 χ。
2. 对 r=1,…,R−1 应用 `χ(iota_RC[s+r](L(state)))`。

第一个常数 `RC[s]` 可通过均匀输入平移吸收。因此这里的 X 是第一个 χ 的输入；首个线性层与首个常数都不在采样函数内部执行。**其余常数保留**。

例如三轮验证使用 χ、`L→iota_0x5a→χ`、`L→iota_0x4b→χ`。`--start-round NUMBER` 可指定其他合法起始轮号；`--constants zero` 可另外比较无常数版本，两者应分别记录。

输出相关度定义：

`rho = E[(-1)^(Lambda · (F(X) xor F(X xor Delta)))]`

样本估计为 `(n0−n1)/N`，保留符号。表格展示 `log2(abs(rho))`；它不是偏差，也不是相关度平方。95% 区间采用二项概率 p 的 Wilson 区间再映射 `rho=2p−1`，在观测全为同一奇偶值时仍有非零宽度。区间逐项有效，未对所有比较作同时覆盖校正。模型在区间外只是一项诊断，不自动判定实现错误。

## 位序与 CSV 格式

- 状态为 `x[0]…x[4]` 五个 64 位字。
- `column=0` 是每个字的最低位。
- `pattern` 是 1…31 的整数，二进制第 i 位选择 `x[i]`。
- CSV 的 `(input_col,input_pattern)=(0,1)` 表示 `x[0]` 第 0 位。
- `(output_col,output_pattern)=(19,8)` 表示 `x[3]` 第 19 位。
- HTML 对单比特端点用 `(行,位)`，即上述两者分别显示 `(0,0)` 和 `(3,19)`。
- `input_words`、`output_words` 按字序列出五个 16 位十六进制串，以分号分隔。
- 零值没有有限对数，CSV 的 log 字段留空；不会输出伪造的负数指数。

## 模型计算

设 `C[v,u] = 2^-5 sum_x (-1)^(u·x + v·chi(x))`。零状态值掩码模型在每列维护 32 个分量 q[v]。

非线性更新：

`q_out[v] = sum_u C[v,u]^2 q_in[u]`。

线性更新时，先计算 `u = L^T embed(j,v)`，再用

`q_new[j,v] ≈ product_k q_old[k,u_k]`。

这个乘积近似忽略不同列之间的依赖。模型中的加常数不会改变零状态值掩码分量；不能据此推出真实多轮相关度与常数无关。

首轮独立枚举 χ 的所有输出差分 b，以 `DDT[a,b]/32` 为权重，对每个分支完成后续传播再加权。不能先把这些分支平均再进行乘积近似，也不能把各分支绝对值相加。

非零输入 a 的 DDT 支撑大小为 4、8 或 16。实现使用 `long double` 并记录乘法/浮点下溢；没有任意精度保证。数值零本身不构成真实相关度为零的证明。

## 两轮精确核对与四轮模型退化

两轮、单活跃输入列和单活跃输出列的特殊结构允许额外精确核对。给定首轮活跃列的全部值，其他 63 个 χ 输出列仍相互独立且均匀。测试验证：对于全部 64×64 个输入/输出列位置，线性层从其他列到目标 5 比特列的映射均具有秩 5。因此第二个 χ 的目标列在这个条件下均匀，其相关度可以由首轮 32 个输入值和第二个 χ 的 32 个局部基值精确枚举。该结论只覆盖上述两轮、单活跃输出列设置。

在当前零状态值掩码模型中，四轮及以后出现完全退化：测试遍历首轮所有 31 个非零输出差分，确认第四个 χ 之前的 61504 个非平凡局部线性相关度乘积都包含精确零因子。进入该步之前的量都是精确可表示的 1/16 倍数，所以此处不是浮点下溢。接着 χ 的置换性使各非零局部掩码相关度仍为零，后续轮数继续为零。

这说明该模型在这里不能继续提供有效候选，**不能据此断言 Gaston 四轮的真实差分线性相关度为零**。继续研究更长轮数需要保留更多联合信息、扩展精确前段或采用其他估计方法，并以实际置换采样检验；当前程序不会自动把另一种模型的结果混入本表。

`alpha={(0,0),(1,4)}, beta={(0,0),(1,56)}, L^T(beta)=alpha`。

各类种子在两侧增加 χ 后都能构造 `chi -> L -> chi` 的线性特征，局部 LAT 乘积的绝对值为 2^-4，即平方相关度权重为 8。这个值是单条特征的局部乘积，不是整体线性包的相关度。

枚举还确认这 10 类种子之间不存在通过一个 χ 直接连接的 LAT 非零转移（包含所有相对共同移位）。因此不能把 2→2 模式直接重复若干次，就声称得到每轮只有两个活跃 S 盒的任意长特征。多轮线性搜索必须允许中间活跃数增多，并按累计 LAT 权重优化。

真正接在中间段后的线性尾段是 `(L -> chi)^r_l`。如果先搜索 `chi -> L -> ... -> chi`，还必须把其输入掩码通过最前的 `L^T` 拉回到与中间段相接的边界。整个区间只省略第一个 L，不能给每个分段分别省略一个 L。

后续线性候选池应保存多种输入/输出掩码、逐轮掩码、相关度符号、w_l=-log2|c_l|，以及首尾边界；不要把端点固定为单活跃列或沿用参考 MILP 中硬编码的示例输入。拼接初筛采用 `w_d+w_m+2*w_l`，最后对选定的外部差分与掩码重新评估整体相关度。

### 已加入两轮 2→2 线性路径池（2026-10-16）

上述 10 类现在均已补齐前后两个 χ 的**全部非零 LAT 转移**，存入
`results/datf_pools/pools/linear_two_2to2.jsonl.gz`，池清单键为
`linear_two_2to2`，匹配汇总名为 `L2_2to2_pool`。
[抵消原理与枚举报告](results/datf_pools/pools/linear_two_2to2.html)列出全部类别。

设两轮路径为 `a1 -> χ -> b1 -> L -> a2 -> χ -> b2`，则
`b1 = L^T(a2)`。由于 `L = ρ_west ∘ θ ∘ ρ_east`，先计算
`d_i = ROTL(a2_i, -WEST_i)`。全部 10 类均满足 `xor_i(d_i)=0`：
两个比特在不同行的同一列抵消，因此 `θ^T(d)=d`，再按 `-EAST_i`
移位得到 `b1`。这里是转置线性层的列奇偶校验抵消，不要求差分侧的
`P=Q=0` 双条件。任意行对 `i<j` 与共同列 `k` 对应：

- `a2` 的比特位于 `(i,k+WEST_i)`、`(j,k+WEST_j)`；
- `b1` 的比特位于 `(i,k-EAST_i)`、`(j,k-EAST_j)`；
- 列坐标模 64，共 `C(5,2)=10` 个共同循环移位类别。

每类第一轮 χ 有 `4²=16` 个前驱，第二轮 χ 有 `10²=100` 个后继。
总计 **16,000 个路径代表、1,024,000 条移位展开路径**。
每轮两个活跃列，内部 `b1,a2` 各两个比特；外部 `a1` 重量为 2–6，
`b2` 重量为 2–10。单轮池的外部比特上限不用于此两轮池。

| 5 | 10 | 5,120 | 327,680 |

### 精确前缀计算

定义 `G=chi o (L+rc) o chi`。对固定的首个 χ 输出差分 β，令 δ=Lβ。由于 χ 是二次映射，`gamma · D_delta chi(y)=h·y+k` 是 y 的仿射函数。拉回 `H=L^T h` 后，首轮不活跃列的 χ 输出仍然独立均匀；只要 H 在这些列非零，该分支贡献就严格为零。其余分支在每个活跃列 j 计算带条件的整数和：

`A[a,b,H_j] = sum_{x : chi(x)^chi(x^a)=b} (-1)^(H_j·chi(x))`。

分支贡献为 `(-1)^(k+h·rc) * product_j A[Delta_j,beta_j,H_j] / 32^m`，m 为首轮活跃列数。遍历各列可达 β 后作带符号求和。这里保留了条件值依赖，没有把首轮差分事件与第二轮基值分布擅自独立化。实现仅对短前缀有效，复杂度随活跃列数增长。

`tests/test_fixed_tail.py` 将该 DDT/Walsh 算法与独立的首轮活跃输入值直接枚举比较，覆盖单列、双列、多种连接掩码与常数。四组 2^22 对的真实前缀采样也支持精确值 0、1/2、1，完整采样计数见 `prefix_experiments.csv`。完整 R 轮评分太弱，未声称用此样本量测出它；若真实相关度为 2^-39，直接测量的样本数量级约为 2^78。

### 完整枚举与 11 个类别

每个比特 (i,p) 对应一条从 P 列 p 到 Q 列 p+t_i 的边。两个方向都是三列、每列两个比特，因此形成一个有 3+3 个顶点、六条边的度为 2 的二分图。由于 t_i 互异，不可能有重边；这样的图只能是一个六边形。将一个 P 顶点移至第 0 列，遍历前五条边的行号，再由闭合条件确定第六条边，即可完整枚举。

另外实现独立方法：枚举第 0 列的行对与第二个 P 列的行对，按 Q 的两位签名查询第三个 P 列行对，使三个签名异或为零。两种算法分别得到 66 个有向六边形表示和 33 个含第 0 个 P 列的状态表示，按共同循环移位去重后均为 **11 个等价类**。各类轨道长均为 64，共 **704 个不同状态**。只允许五行共同移位，不按行置换合并。

### 实现与普通 DATF 假设

`tools/datf.py` 实现 GF(2) 布尔多项式、变量定义 DAG、原始孤立变量估计循环与独立边际 Bias；`tools/datf_k06.py` 实现 Gaston 的符号传播和四项任务。

同时传播基准状态 a 和差分 d。下标按模 5 计算，每一列有：

```text
a'_i = a_i + a_(i+2) + a_(i+1)*a_(i+2)
d'_i = d_i + d_(i+2) + a_(i+1)*d_(i+2)
                       + d_(i+1)*a_(i+2) + d_(i+1)*d_(i+2)
```

这里 `+` 是 XOR，`*` 是 AND。第一轮直接计算 χ；之后每次先计算 L 和 iota，再在下一层 χ 前做过渡变量替换。含两个以上变量的表达式引入 α、β；零变量、单变量表达式保留；相同或互补的 β 表达式复用变量。全部精确定义保存在各任务 JSON 的 `dag` 字段中。

估计按原始 Algorithm 1 执行：将当前表达式分为非孤立部分 e* 和孤立变量之和 e_l，计算 e* 在独立边际分布下的相关度并乘入累计值，再同时回代全部孤立过渡变量，重复该步骤。原始输入和 α 的边际取均匀，β 的边际用同一原算法递归估计。Bias 用分离变量连通分量与 Shannon 分解作精确有理数计算。

**代数 DAG 是精确表达，偏差估计依赖独立性假设**。同层完整状态的 α 坐标均匀，并不意味着 α 与历史输入、β 或其他轮 α 联合独立；非孤立变量的边际乘积、不同回代步骤产生的因子相乘也会丢失依赖。

转换规则参考[原作者公开代码 QHCrypto/DATF](https://github.com/QHCrypto/DATF)，固定提交 `e5759a5fbdad660ead7d0058914c5a46b79e0f0f`；估计循环核对 [2025/1632](https://eprint.iacr.org/2025/1632) 第 2.4 节重述的**原始 Algorithm 1**。这里只使用该节对普通方法的定义和比较例，没有实现增强 DATF。作者部分 Ascon 专用脚本末尾采用手工多次展开 β；本实现是面向 Gaston 的原算法实现，不声称逐行移植这些脚本。参考源码及原 MIT 许可证保存在 `vendor/datf_reference/`。

没有采用增强版的转换阈值、最新变量回溯、输入空间划分或增强 Bias 预处理。每项资源上限默认 1,000,000 个 Bias 节点，超限标记 `resource_limit` 并令相关度为 `null`，绝不把未计算记作零；本次四项均未超限。

### 零因子审计与解释

原算法逐步得到的因子如下，**因子对应估计器的剥离步骤，不是轮分段权重**：

| 对象 | 估计因子乘积 | Bias 节点数 |
|---|---|---:|
| 两项三轮前缀 | 2^-22 × 0 | 各 755 |
| 完整五轮 | 2^-20 × 2^-18 × 0 | 42,487 |
| 完整六轮 | 2^-22 × 2^-50 × 0 | 113,918 |

`tools/datf_audit.py` 用独立二次多项式消元核对所有这些因子：对 `uv+uA+vB+C` 先求 u、v 的平均，等价于 `1/2 * (-1)^(C+AB)`。存在非均匀边际时，先固定其取值并按精确概率加权，余下均匀变量再做二次消元。五轮零因子中有一个非均匀变量，两种取值的剩余表达式都平衡。此程序是估计器结果的复核，不是增强 DATF 或新的相关度估计。

三轮前缀的第二个因子有 131 个变量、187 项；独立均匀模型下存在平移 h，使 `f(z xor h)=f(z) xor 1`，因此相关度为零。两个三轮配置都找到 `h={320,612}`，变量编号对应保存的 DAG。该平移是在假想独立变量空间中定义的，未证明它对应真实输入空间的平移。

这一步含 13 个第一层 β 和 11 个原始输入坐标。模型把它们当成 24 个独立坐标，而它们的实际仿射秩只有 12，有 12 条线性关系被忽略。该事实确认了依赖损失，但没有证明这些关系是估计失效的唯一原因，也没有确定实际相关度的符号或大小。

所以，不能从本次零输出推断其他路径恰好抵消了 −2^-23，也不能反过来把 −2^-23 当作实际前缀相关度。当前普通方法没有为这些端点提供非零整体估计；实际值还需要能够保留相关依赖的独立计算来确定。

本次优化目标为单条路径组合的带符号拼接评分：

```text
S = p_D * rho_middle_DATF * c_L^2
delta_middle = L(last_differential_chi_output)
gamma_middle = transpose(L)(first_linear_chi_input_mask)
R = r_d + r_m + r_l
```

其中 `c_L` 是一条线性路径的相关度乘积，不是线性包相关度。**S 不等于完整端点相关度，也不是它的严格上下界**。中间段使用均匀基准输入，未保留前段路径事件造成的全部条件分布；没有对不同差分分支、线性路径及交叉项聚合。因此其数值不能与旧报告的限定分支和直接混称，例如旧 K06 的两条同号贡献和会比单条评分大一倍。

仍只省略第一个整体 L。分段边界的 L 都计入，采用参考实现末 R 轮，起始轮号 `12−R`。中间段首个常数通过该段模型的均匀基准输入平移吸收；两轮中间段内部保留 `RC[11−r_l]`。

### 搜索覆盖与移位约简

固定线性代表、只展开差分侧的完整循环轨道即可覆盖相对位置。有周期 32 的单轮路径时只展开 32 个不同状态。对本次普通 DATF 的一、两轮中间段，绝对单条评分还满足共同循环移位不变性：第一层 β 为原输入的仿射函数；第二层 α 的常数只在孤立 α 回代时留下符号相位，其他 Bias 因子按均匀变量计算。因此轮常数不改变此特定模型的绝对值。这不证明实际完整置换相关度或带符号路径和有相同的移位对称性。

- 一轮中间段 × 11 个论文尾段：两个差分池均已穷尽；每尾段分别计算 812,800、2,883,584 对。
- 一轮中间段 × 单轮线性池：按 `w_D + 2*w_L` 递增，耗尽所有较低权重层后取得第一条非零连接。单 χ 的非零导数相关度为 ±1，因此已证明这两个池内的最佳单条评分分别是 2⁻⁴、2⁻²⁸；没有枚举全部同分者。
- 两轮中间段 × 论文尾段：每类差分池选 256 个代表并展开所有不同移位。D1 为 16,352 条，D2 为 16,384 条。D2 在 11 个 PQ 类之间轮流取候选，优先旧连接及较低中间输入活跃数。
- 两轮中间段 × 单轮线性池：当前选择按 LAT 权重及入口活跃数排序的前 64 个线性代表，每类差分最多计算 262,144 对；本次实际计算 260,096 和 262,144 对。固定尾段仍使用上述完整 256 个差分代表批次。

每种中间长度的完整笛卡尔积超过 470 亿对。两轮中间段的“未找到”只针对当前批次。程序保留完整池、候选选择清单、已计算计数、理论评分界及是否有最优性证书，不把预算外的候选标成零。
