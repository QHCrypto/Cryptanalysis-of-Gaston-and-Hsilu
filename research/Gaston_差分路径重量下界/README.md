# Gaston 差分路径重量下界

本目录用于研究 Gaston 的差分路径重量下界。用户已确认：原始 Gaston-320、非零 XOR 差分路径、自由输入输出差分、局部 DDT 重量之和，第一阶段研究三轮。当前实施方案按照 Hsilu 论文第8.1.1节表14：线性层精确MILP，χ采用lossy模型，以最多16线程、不设时限求解。

当前程序为 [gaston_3round_lossy.cpp](gaston_3round_lossy.cpp)，编译使用 [Makefile](Makefile)。旧求解已按用户要求停止；加入活跃列传播表的新模型已完成验证及连续松弛比较，尚未启动新的整数求解。具体数学模型、验证与运行方法见 [MILP_README.md](MILP_README.md)，加强效果及后续方法见 [活跃列约束加强.md](活跃列约束加强.md)。旧运行记录见 [results/latest_run.json](results/latest_run.json)。后文保留其他候选研究方法供后续使用。

## 研究口径

本方法分析讨论原始 Gaston 的 5×64 位状态、非零 XOR 差分路径、自由输入和输出差分。令第 i 个 χ 的输入、输出差分分别为 a_i、b_i，满足 a_{i+1}=λ(b_i)，其中 λ=ρ_west∘θ∘ρ_east。路径重量定义为

\[
W(T)=\sum_{i=0}^{r-1}\sum_{z=0}^{63}
-\log_2\left(\frac{\operatorname{DDT}_{\chi}[a_{i,z},b_{i,z}]}{32}\right),
\qquad W_r=\min_{T\ne0}W(T).
\]

每个局部 DDT 条目必须非零。这是 restriction weight，即 −log₂(EDP)。多轮实际路径概率及端到端差分簇概率不是这里的目标量。轮常数在局部差分模型中抵消。

## 精确重量及路径核心

χ为二次映射，固定输入差分α后

\[
D_\alpha\chi(x)=\chi(x+\alpha)+\chi(x)=M_\alpha x+c_\alpha.
\]

若β属于该仿射映射的像，则DDT[α,β]=2^{5−rank(M_α)}，因而

\[
w(\alpha\to\beta)=\operatorname{rank}(M_\alpha).
\]

这是局部精确等式。矩阵秩只依赖输入差分，但输出仍必须满足DDT可行性。无需在求解时逐个计算矩阵秩：预计算32项查找表即可。

[局部穷尽审计](results/chi5_audit.json)验证了全部1024个差分对：合法对共317个；32个输入差分的秩分布为0对应1个、2对应5个、3对应15个、4对应11个。输入汉明重量3的列可能具有精确重量3或4，因此仅按汉明重量估计会丢失信息。

对固定输出β定义逆向最小重量

\[
v(\beta)=\min_{\alpha:\operatorname{DDT}[\alpha,\beta]>0}
\operatorname{rank}(M_\alpha).
\]

非零输出中20个的v为2，11个的v为3。自由端点的三轮问题可精确消去两端χ，只保留

\[
b_0\xrightarrow{\lambda}a_1\xrightarrow{\chi}b_1
\xrightarrow{\lambda}a_2,
\]

并以

\[
\sum_zv(b_{0,z})+
\sum_z\operatorname{rank}(M_{a_{1,z}})+
\sum_z\operatorname{rank}(M_{a_{2,z}})
\]

作为精确最小补齐重量。中间χ保留完整DDT约束；要求b_0非零。该化简仅适用于上述自由端点与局部EDP定义。若固定置换输入、固定输出或要求全程基点可实现性，应恢复相应约束。

## 优先路线一 按θ-effect分类并精确排除

对每个内部线性层输入X，令A=ρ_east(X)，定义未施加公共旋转的effect

\[
P=\bigoplus_i A_i,\quad Q=\bigoplus_i\operatorname{ROL}(A_i,t_i),
\quad E=P+\operatorname{ROL}(P,1)+Q+\operatorname{ROL}(Q,18).
\]

θ实际向各行加入ROL(E,23)。本目录统一以E=0定义核内；公共旋转不影响是否为零。P=Q=0仅是核内的一种情形，不能用它替代完整核。

三轮核心有两个内部λ，完整划分为(K,K)、(K,N)、(N,K)、(N,N)，其中K表示E=0，N表示E≠0。每一类证明下界L_c后，取min_c L_c得到全空间下界。不同类别可使用不同方法。

核外部分继续按E的重量、支撑及循环移位轨道分类。复用既有二分图匹配下界，优先排除大部分effect；保留下来的小匹配effect交给精确χ模型。核内部分保留完整线性条件E=0，研究低重量状态和相邻χ的兼容性。

对于整数阈值B，精确判定“存在非零r轮路径且W≤B−1”。若完整编码及所有分类实例均获独立检查通过的UNSAT证明，则W_r≥B。若找到重量U的合法路径，则W_r≤U。超时没有完成下界证明。

现有47条CNF比完整DDT少16个合法转移，均来自输入11111。审计确认前46条恰好刻画完整DDT支撑。后续应在本目录新建完整模型，保留旧目录的实验口径。旧模糊重量本身是有效下估计：在覆盖全部路径的模型中，其阈值UNSAT同样能证明下界，但SAT候选须回算精确重量。

## 优先路线二 低重量路径核心的完备枚举

可借鉴[Keccak路径树搜索方法](https://keccak.team/papers.html)及[Tighter trail bounds for Xoodoo](https://eprint.iacr.org/2022/1088)：构造规范化核心、计算对全部后代有效的代价下界、向前或向后扩展，并证明阈值以下空间已被覆盖。

Gaston的可用剪枝包括：χ导数秩、逆向最小重量、effect支撑的匹配下界、活动列预算及GF(2)一致性。当前部分状态的重量可能被后续异或抵消，不能直接当作所有后代的下界。同步旋转64列保持本地差分传播及重量，可据此选择轨道代表；任意固定某一行单比特不一定保留所有轨道。

为降低一次性实现成本，可先枚举低预算effect或核心类别，再为每个类别调用SAT；专用枚举与通用求解器分别承担结构覆盖和局部可行性判断。

## 辅助路线 线性码和多轮拼接

集合C_λ={(X,λ(X))}是二进制线性码，但目标应采用每5比特一组的列重量，不能直接套用普通比特最小距离。固定effect后得到仿射陪集，指定输入输出活动支撑后可用GF(2)消元排除不一致情形。进一步用χ的秩代价区分列值，通常比只计数非零列更有希望。

若已证明W_k≥L_k，则在非零差分、自由端点及同一局部重量定义下，任意非重叠分段给出

\[
W_r\ge\sum_j L_{k_j},\qquad \sum_jk_j=r.
\]

例如原论文的两轮界24及单轮界2推出基线24⌊r/2⌋+2(r mod 2)。这只是已有短轮界的推论。核外相邻两χ另有w_i+w_{i+1}≥32，但重叠窗口共享χ层，不能把这些32直接相加；应解小规模整数规划或使用每层总覆盖系数至多1的加权不等式。

更强方向是记录短核心的边界差分、核类型、effect类别及兼容性，形成带权转移图，再用最短路或min-plus动态规划。边权必须是已证明的下界，且每条真实路径必须映射到图中。允许额外的虚假连接会使下界变松，遗漏真实连接则会使结论失效。

## 建议实施顺序

1. 已确认标准重量定义、自由端点及三轮目标。
2. 当前先完成并运行Hsilu表14的lossy模型，线性层逐位精确。
3. 后续可比较精确χ重量、逆向重量表和完整DDT关系对下界的改善。
4. 需要时完整覆盖四种核类型，逐类加入匹配、支撑秩和短窗口剪枝。
5. 后续独立证明阶段保存编码、覆盖清单、UNSAT证书及检查记录；当前Gurobi运行不声称已经生成此类证书。
6. 若通用模型瓶颈明确，再开发专用路径树；获得三轮或四轮界后做多轮拼接。
