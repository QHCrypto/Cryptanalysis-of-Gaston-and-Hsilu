# GastonCube：六轮一次密钥、63 次 nonce 系数

汇报中的旋转不变偶校验 Cube 已另行实现，见 [三次 Cube 求和与 MILP 单项式预测](PARITY_CUBE.md)。入口为 `gaston_parity_cube.cpp`；本页下面仍描述独立原始坐标 Cube。两者共用 `gaston_mp.hpp`，但输入方向空间及结果目录不同。

## 研究对象与当前状态

用户确认研究初始化输入

\[
S=(\mathtt{0x00001000808c0001},K_0,K_1,N_0,N_1)
\]

经过六轮 Gaston 后的 `S0,S1`。关联数据为空、首个明文块为全零，因此这 128 位就是首个密文块。初始化后的密钥注入位于 `S3,S4`，不会改变此观察位置。

目标为

\[
A_{j,i}(I)=[k_i\prod_{t\in I}n_t]C_j(k,n),
\qquad 0\le i,j<128,\quad |I|=63.
\]

**尚未获得六轮系数为 1 的完整证书**。已经建立可行性与完整奇偶性枚举模型，并通过独立的完整布尔计算验证。六轮可行轨迹不是系数为 1 的证书。结果中的 `coefficient:null` 表示未知，绝不能读为 0。

2026-10-22 的初步模型比较选取

\[
I=\{0,2,4,\ldots,124\}.
\]

具体对应 `N0` 的 32 个偶数位，以及 `N1` 的 `0,2,...,60` 共 31 位。其余 65 个 nonce 位固定为零。这里的 63 个变量都是原始独立输入位，没有额外的奇偶约束或变量替换。

这只是四个候选中、使用旧版混合密钥次数电路（`--key-split 0`）、固定 `k0` 和 `S0[0]` 时二进制变量数最少的候选，**不是已证明全局最快的 Cube**。下表记录这一初始选取依据；增加逐轮密钥次数拆分后没有改变研究所用的坐标集合。

| 原始 nonce 坐标集合 | 二进制变量 | 约束 |
|---|---:|---:|
| `0,2,...,124` | 102673 | 4818 |
| `64,...,126` | 104165 | 4831 |
| `0,...,62` | 109411 | 4985 |
| `0,...,31` 与 `64,...,94` | 111244 | 5006 |

## 状态与位编号

- 每个字为 64 位，字内 bit 0 为整数最低位，字节使用小端解释。
- `k0..k63` 对应 `K0`，`k64..k127` 对应 `K1`。
- `n0..n63` 对应 `N0`，`n64..n127` 对应 `N1`。
- 输出 `0..63` 对应 `S0`，`64..127` 对应 `S1`。
- 完整参考函数使用 Gaston 最后六个轮常量 `96,87,78,69,5a,4b`。本次最高次系数与轮常量选择无关，见下文证明。
- 小于 64 的字宽只用于辅助验证模型，不代表实际 Gaston。

## 精确的最高次化简

Gaston 的一轮为

\[
F_t=\chi\circ\iota_t\circ L,
\quad L=\rho_{\rm west}\circ\theta\circ\rho_{\rm east},
\quad \chi_i(a)=a_i+a_{i+2}+a_{i+1}a_{i+2}.
\]

一次初始化至多含一次输入变量，故第 r 轮总次数至多为 `2^r`。六轮目标次数 `1+63=64` 达到该上界。由次数归纳，其贡献只能来自每轮 χ 的二次部分及前一轮的最高次部分。IV、轮常量、χ 的一次部分均无法贡献总次数 64。

布尔环按总次数过滤，其关联分次环为

\[
\operatorname{gr}\bigl(\mathbb F_2[x]/(x_i^2-x_i)\bigr)
\cong\mathbb F_2[x]/(x_i^2).
\]

因此，在**仅计算最高次分量**时，可在右侧平方为零的交换代数中计算

\[
H^{(0)}=(0,K_0,K_1,N_0,N_1),\quad
B^{(t)}=L(H^{(t)}),\quad
H^{(t+1)}_i=B^{(t)}_{i+1}B^{(t)}_{i+2}.
\]

其中行下标模 5。最终 `H^(6)` 的系数恰等于完整布尔函数的总次数 64 系数。这不是低次数项的近似模型；**不得把该程序用于六轮次数小于 64 的系数**。

任意正次数元素 P 在这个代数中满足 `P^2=0`，因为特征为 2，且每个非空平方自由单项式的平方为零。程序利用它进行精确抵消：同一中间多项式被选两次的分支整体为零。对于最高次项，源变量不能重复使用。

第一轮二次乘积还会先完整展开、按 GF(2) 消去重复单项式。后续轮保留 SUM/PRODUCT 有向无环电路，共享同一子表达式。

## 逐轮只保留 0 次或 1 次密钥分量

当前默认启用 `--key-split 1`。最初版本只使用了上面的总次数化简，并在 MILP 源约束中要求恰好选择一个密钥；并没有在每轮电路构造时显式拆分密钥次数。现在每轮分别维护

\[
A^{(t)}=H^{(t)}_{\deg_k=0,\,\deg_n=2^t},\qquad
B^{(t)}=H^{(t)}_{\deg_k=1,\,\deg_n=2^t-1}.
\]

初始化为

\[
A^{(0)}=(0,0,0,N_0,N_1),\qquad B^{(0)}=(0,K_0,K_1,0,0).
\]

记 \(a=L(A^{(t)})\)、\(b=L(B^{(t)})\)，则对每一列、行下标模 5，有

\[
A^{(t+1)}_i=a_{i+1}a_{i+2},\qquad
B^{(t+1)}_i=a_{i+1}b_{i+2}+b_{i+1}a_{i+2}.
\]

程序不构造 \(b_{i+1}b_{i+2}\)。这是对目标系数的**精确投影**：在最高次关联分次环中，重复变量的乘积为零；其余乘积的密钥次数相加，不能从至少 2 次回到 1 次。直接在完整布尔环中以“密钥次数不会下降”为理由截断则不成立，因为那里有 \(k_i^2=k_i\)；这里先固定总次数达到上界，才可使用上述论证。

只有 63 个 nonce 变量，故 \(A^{(6)}=0\)，也不必构造其乘积。目标由 \(B^{(6)}\) 给出。固定某个密钥时，其余密钥仍设置为零；`--key all` 保留全部 128 个独立密钥源。

同一 Cube `0,2,...,124`、同一输出 `S0[0]` 的实际建模结果如下，均为求解器预处理前的规模：

| 密钥范围 | 电路形式 | 二进制变量 | 约束 |
|---|---|---:|---:|
| 仅 `k0` | 旧版混合电路 | 102673 | 4818 |
| 仅 `k0` | 每轮 0/1 次密钥分量 | 131672 | 8326 |
| 全部 128 个密钥 | 旧版混合电路 | 831753 | 19142 |
| 全部 128 个密钥 | 每轮 0/1 次密钥分量 | 496454 | 16063 |

全部密钥模式的二进制变量减少约 40.3%；固定单个密钥时则增加约 28.2%。显式分解也增加了交叉乘积和中间节点，因此不能把代数截断直接等同于 MILP 加速。这是**模型规模观察**，尚未测得六轮完整计数的运行时间收益。可运行 `python3 src/compare_key_split.py` 重现比较；原始结果位于 `results/key_split_comparison/`。

分解可能改变局部抵消和剩余路径条数，但完整路径奇偶性必须相同。例如已验证的三轮目标 `k106`、nonce 集合 `12,17,18,26,42,101,112`、输出位 127，旧电路有 169 条路径，新电路有 153 条路径，二者系数均为 1，并与完整布尔穷举一致。

## 与 Cube 超多项式的关系

固定其他 nonce 为零，63 维 Cube 的超多项式满足

\[
S_{I,j}(k)=\bigoplus_{n_I}C_j(k,n_I,0)
=b_j+\sum_{i=0}^{127}A_{j,i}k_i.
\]

这来自 `deg C_j<=64`，不是由随机线性测试推测。程序研究 `A`，不计算常数项 `b`。此外，改变非 Cube nonce 的常量值不会改变 `A`：若额外含一个非 Cube nonce 位，相关单项式次数至少为 65，超过上界。常数项 `b` 则可能改变。

最高次模型不含轮常量，各个旋转、混合与 χ 的二次部分均与统一字内旋转可交换。因此，一个精确系数证书也可同时旋转所有密钥、nonce 和输出的字内索引，得到对应旋转 Cube 的证书。不能只旋转密钥或输出而固定 Cube 后直接复用结论。

## MILP 的确切含义

节点活动变量 `a_v` 和 SUM 分支变量 `e_(v,u)` 均为二进制。

- SUM 节点：`sum_u e_(v,u)=a_v`，选择一个代数项。它不是状态值的异或方程。
- PRODUCT 节点：活动时必须选择所有因子。
- 每个节点：`a_v = root_indicator(v) + sum(使用它的活动边)`。二进制上界排除重复使用正次数因子。
- 所选 63 个 nonce 源全部活动；密钥源恰好活动一个。固定单个密钥的模式会把其他密钥变量设为零，仍精确保留目标的一次密钥系数。

模型可行解是一条经过上述精确局部化简后的单项式贡献路径。系数等于全部这些贡献路径数模 2；`--key all` 时按其密钥源分别累计。

`screen` 仅做可行性检验。不可行可证明相应目标系数为零；可行只报告 `feasible_only`。`count` 使用 Gurobi `PoolSearchMode=2` 完整枚举，每批加 no-good 排除已经计数的路径。只有解池已穷尽或后续模型已证明不可行，才写入 `complete:true` 和系数。

**当前瓶颈是完整奇偶性计算**。即使一次可行性求解数秒完成，全部路径计数也可能非常大。部分路径的奇偶性没有最终系数含义。本次没有把任何求解超时或未完成任务标成系数 0。

## 使用

Gurobi C++ 默认路径 `/opt/gurobi1302/linux64`，可通过 `GUROBI_HOME` 覆盖。控制台日志保持开启，程序不设置求解时间上限。`Ctrl+C` 请求求解器终止，已提取的完整路径保存至 checkpoint，结果保留未知状态。

```bash
cd /home/yxb/分析/GastonCube
make
make test
python3 src/compare_key_split.py
```

`src/select_cube.py` 会重新选取并写入 Cube 配置；初始选取使用 `--key-split 0`。继续当前坐标集合的计算不需要重新执行选取脚本。

计算选定 Cube 的完整 128×128 一次密钥系数矩阵：

```bash
python3 src/run_matrix.py
```

该命令可能运行很久。目前没有完成耗时估计。它默认逐轮拆分密钥次数，逐个输出位处理，结果写入 `results/matrix_split1/matrix.json`，未知条目为 `null`。每个输出位一份 checkpoint；再次执行会接续而不是把部分路径当成新任务重计。传入 `--key-split 0` 则使用旧电路及 `results/matrix/`，两种电路的路径 checkpoint 分开保存。

只计算某个输出位的 128 个一次密钥系数：

```bash
python3 src/run_matrix.py --outputs 0
```

直接对一个指定项计算：

```bash
./gaston_cube --rounds 6 --key 0 --nonce 0-62 --output-bit 0 \
  --mode count --result results/example.json --checkpoint results/example.trails
# 已有 checkpoint 时，在同一命令末尾添加 --resume，并保持相同的 --key-split 设置。
```

上面的直接示例用连续坐标 Cube，与配置选中的偶数坐标 Cube 不同。要使用配置集合，可运行 `src/run_matrix.py`，或把 `cube_config.json` 的 `nonce_indices` 逗号连接后传给 `--nonce`。

初始后台任务 `results/r6_even_k0_o0.trails` 使用旧版混合电路。新程序接续它时必须加 `--key-split 0`，且不得在旧进程仍运行时重复接续同一文件。程序会拒绝模型散列不匹配的 checkpoint，不会将两种电路的部分路径奇偶性混合。

## 验证与结果文件

- `reference/gaston.py`：独立完整布尔参考，含 IV、轮常量和 χ 低次项。
- `tests/validate.py`：对照原作者 C 实现；对 1–3 轮小 Cube 穷举计算；分别核对新旧电路的系数 0/1、偶数路径抵消、分批计数和续算，以及不兼容 checkpoint 的拒绝行为。
- `results/validation_summary.json`：验证计数及源码散列。
- `cube_config.json`：用户确认的研究口径及候选比较。
- `results/r6_even_k0_o0_count.json`：当前单个六轮目标的精确计数状态。是否完成应读取文件，不以本说明的写入时间判断。
- `results/r6_even_k0_o0.trails`：当前单项目标的续算文件；它与完整矩阵脚本的 checkpoint 不是同一个任务。

实际 64 位字的验证已通过：128 次原作者参考比对、320 个线性层基向量、56 个逐项系数检查（新旧电路各 28 次，含抵消）、8 次常量/轮区间改变检查、分批续算及不兼容 checkpoint 检查，以及一个输出位的 128 个密钥系数分别用两种电路联合恢复（共 256 次比较）。这些验证不能替代六轮目标的完整求值。

## 下一步研究方向

原始路径枚举是可复核基线。若六轮规模不可接受，应采用保持奇偶性信息的分组：在中间状态展开，只保留对目标有贡献的单项式；对第一线性层的 64 个形式乘积，用目标变量上的 64×64 行列式精确求其最高次系数；再按中间单项式合并上层贡献。局部行列式为 1 仍不代表完整六轮系数为 1，必须继续完成上层全部贡献的异或。

本目录仅复用了相邻 `Cube/gaston_monomial_prediction/gaston_mp.cpp` 中已核对的最高次电路思路；没有把其中带 nonce 等式/周期参数化的旧结果移植为原始 63 个 nonce 坐标的结论，也未修改旧目录或它的运行任务。
